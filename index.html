Speech is turned into text on this device, and your voice never leaves it. Your words go only to your own GitHub repo, straight from this browser, when you press Send.

Send ideas to GitHub

Each idea you send becomes an issue in a repo of yours. Sayfold has no server: your token and your text go straight from this browser to GitHub's API (api.github.com), and nowhere else.

  1. Open a new fine-grained token on GitHub.
  2. Under Repository access, pick Only select repositories and choose this one repo.
  3. Under Permissions, set Issues to Read and write. Nothing else is needed.
  4. Generate it, and paste it above.

Kept in this tab's memory only, and gone when you close it.
